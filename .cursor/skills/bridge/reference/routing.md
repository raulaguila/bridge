# Command guidance

Bare `/bridge` — recommend **2–3** `/bridge …` commands, never auto-run, never suggest `/keel` or `/impeccable`.

| Signal | Lead with |
|--------|-----------|
| No PRODUCT.md | `init` |
| PRODUCT yes, no CONTRACT / draft | `contract` |
| CONTRACT accepted, no sequence yet | `plan` |
| Plan has open craft steps | `build` |
| Artifact/CONTRACT validation | `doctor` |
| FE and BE both moving | `sync` |
| “Are we ready to launch?” | `ship` (after `sync`) |
| Backend- or frontend-shaped request while in Bridge | `build be:…` or `build fe:…` |

After any command: [next-commands.md](next-commands.md).
