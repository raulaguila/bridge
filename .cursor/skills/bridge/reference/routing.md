# Command guidance

Bare `/bridge` — recommend **2–3** commands, never auto-run.

| Signal | Lead with |
|--------|-----------|
| No PRODUCT.md | `init` |
| PRODUCT yes, no CONTRACT / draft | `contract` |
| CONTRACT accepted, no sequence yet | `plan` |
| FE and BE both moving | `sync` |
| “Are we ready to launch?” | `ship` (after `sync`) |
| User wants exact `/keel` `/impeccable` lines | `handoff` |
| Backend-only or frontend-only | Tell them to use Keel or Impeccable directly |

After any command: [next-commands.md](next-commands.md).
